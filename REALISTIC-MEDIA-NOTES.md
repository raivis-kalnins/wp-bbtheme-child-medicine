# Realistic demo media refresh

This 3.8.10.30 release replaces placeholder/screenshot-style demo media with photographic assets where the theme uses seeded demo content, and adds a six-image photographic pool for demo blog featured images.

Most visual assets are original/generated media bundled with this theme suite. A small set of scientific/general sample photographs used for the Medicine, Restaurant, E-learning and Travel demos comes from scikit-image data with public-domain / CC0 status documented by scikit-image (for example: coffee by Rachel Michetti, NASA astronaut imagery, SpaceX rocket imagery, retina/cell scientific imagery).

No remote image hotlinks are required at runtime; all demo images are bundled locally in the theme.
